### X Video Staging Lessons

- Use `https://x.com/compose/post` for a clean modal composer. The home timeline
  inline composer kept stale media state and made the stuck upload harder to
  clear.
- Fill post text first, then re-snapshot. X invalidates refs after editor
  changes.
- Upload with `input[type="file"]` instead of an accessibility ref when refs
  become stale.
- Do not upload the raw Remotion MP4 to X without checking encoding. The first
  file was locally playable but stayed in X processing:
  - `my-remotion-demo/out/sites-lifecycle.mp4`
  - video only, full-range `yuvj420p`
- Convert to an X-compatible MP4 before staging:
  - Preferred command: `npm run build:sites:x` from `my-remotion-demo`.

```bash
ffmpeg -y \
  -i my-remotion-demo/out/sites-lifecycle.mp4 \
  -f lavfi -i anullsrc=channel_layout=stereo:sample_rate=44100 \
  -shortest \
  -vf "scale=in_range=pc:out_range=tv,format=yuv420p" \
  -c:v libx264 -pix_fmt yuv420p -profile:v high -level 4.0 \
  -preset veryfast -crf 20 \
  -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
  -movflags +faststart \
  -c:a aac -b:a 128k \
  my-remotion-demo/out/sites-lifecycle-x-compatible.mp4
```

- Ready state to wait for:
  - `<filename>: Ready`
  - visible video preview
  - `Remove media` button exists
